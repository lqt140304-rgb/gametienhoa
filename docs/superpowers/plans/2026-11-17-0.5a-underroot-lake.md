# 0.5a — Hồ Khởi Sinh, bậc D, quần thể theo vùng: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Một scene `Underroot_Lake` 120 × 120 m chơi được, nơi sinh vật D/C/B đến từ quần thể của vùng (không còn máy đẻ quái), kẻ săn B đi vào từ rìa có vết rung báo trước, và xác sinh vật thối dần qua 3 giai đoạn.

**Architecture:** Logic quần thể và xác là **C# thuần** (không MonoBehaviour) để test bằng EditMode; các MonoBehaviour mỏng (`Region`, `Den`, `PredatorIncursion`, `Carcass`, `VibrationEmitter`) nối logic đó với scene. Scene được dựng bằng menu Editor mới, tái dùng prefab `Prey`/`Predator` và các helper của `PrototypeSceneBuilder`. Mô phỏng chạy cục bộ ở mỗi máy như 0.4a (đồng bộ quái là việc của 0.4b, ngoài phạm vi).

**Tech Stack:** Unity 6.6 (`6000.6.9f1`), URP, C#, Unity Test Framework (EditMode), assembly `Evolve` / `Evolve.Editor`.

**Spec:** `docs/superpowers/specs/2026-11-17-underroot-survival-slice-design.md` (mục 5, 6.1, 6.7.1, 6.7.2, 7)

    - `int Available => Count - Embodied`
    - `bool TryEmbody()` (Available > 0 → Embodied++), `void Store()` (Embodied--, không âm), `void Kill(bool wasEmbodied)` (Count--, nếu wasEmbodied thì Embodied--; không âm).

  3. Kẻ săn (có `PreyId`): giết `min(prey.Available, Count*KillsPerHeadPerMinute*minutes)` con mồi không hiện thân.
  4. Sinh: chỉ khi `Dens > 0` và đủ ăn; `+BirthsPerMinute*Dens*minutes`, kẹp `Capacity`.
