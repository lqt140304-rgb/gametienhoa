# 0.5b — Khát, nước, nơi trú ẩn, Căng thẳng, HUD tối giản: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Slime phải lo thêm **Khát** (uống ở vùng nước), **Căng thẳng** (tăng khi bị đánh/đói/khát/quá nóng lạnh, giảm ở nơi trú), có **nơi trú ẩn** thật, **kích thước thân theo số cơ quan** (to quá thì không chui lọt khe trú), và một **HUD tối giản** chỉ hiện chỉ số đang có vấn đề, còn lại thể hiện trên thân slime.

**Architecture:** Luật khát/căng thẳng là C# thuần trong `SurvivalState` + các hàm tĩnh `StressEffects` để test bằng EditMode. Vùng nước và nơi trú là MonoBehaviour trigger mỏng, có sensor gắn trên slime (giống `ClimateSensor`). Mỗi chỉ số do **máy của chính người chơi** tính (đúng spec 6.6); co-op không đồng bộ thêm gì ở bản này.

**Tech Stack:** Unity 6.6 (`6000.6.9f1`), URP, C#, Unity Test Framework (EditMode), assembly `Evolve` / `Evolve.Editor`.

**Spec:** `docs/superpowers/specs/2026-11-17-underroot-survival-slice-design.md` (mục 5, 6.2, 6.6, 6.7.4, 6.7.5). Bản 0.5a đã nằm trong `main`.

### Task 1: Luật Khát và Căng thẳng (C# thuần)

**Files:**
- Modify: `Scripts/Survival/SurvivalConfig.cs`, `Scripts/Survival/SurvivalState.cs`
- Create: `Scripts/Survival/StressEffects.cs`
- Test: `Tests/EditMode/SurvivalThirstStressTests.cs`

**Interfaces:**
- Produces:
  - Trong `SurvivalConfig` (các giá trị mặc định ghi sẵn, đều chỉnh được ở Inspector): `ThirstDecayPerSec = 0.35f`, `ThirstSprintExtraPerSec = 1.0f`, `ThirstHotExtraPerSec = 0.3f` (khi `Ambient > ComfortMax - 5`), `DrinkPerSec = 25f`, `DehydrationDamagePerSec = 3f`, `HealThirstThreshold = 0.5f`, `StressPerDamage = 0.5f`, `StressLowNeedsPerSec = 0.4f` (đói hoặc khát dưới 25%), `StressBadTempPerSec = 0.4f`, `StressCalmDecayPerSec = 0.3f` (đủ ăn đủ uống: Hunger ≥ 70% và Thirst ≥ 50%), `StressShelterDecayPerSec = 2f`, `ShelterEnergyRegenMultiplier = 2f`, `StressHighEnergyRegenMultiplier = 0.5f`, `StressShakeStart = 40f`, `StressSenseStart = 60f`, `StressEnergyStart = 80f`.
  - Trong `SurvivalState`: `public float MaxThirst = 100f; public float Thirst; public float Stress; public const float MaxStress = 100f; [NonSerialized] public bool ThirstEnabled; [NonSerialized] public bool InShelter; public void Drink(float amount)`. Hàm công khai `Damage(float amount)` hiện có **cộng thêm** `amount * Config.StressPerDamage` vào `Stress` (cú đánh từ bên ngoài như kẻ săn cắn). `SurvivalState` giữ `[NonSerialized] public SurvivalConfig Config` do `SurvivalStats.Awake` gán (null thì không cộng căng thẳng). Sát thương từ đói, khát, nhiệt độ trong `Tick` đi qua `private void ApplyDamage(float)` **không** cộng căng thẳng theo cú đánh (căng thẳng của chúng đến từ tốc độ `StressLowNeedsPerSec`/`StressBadTempPerSec`).
  - `Reset()` đặt `Thirst = MaxThirst`, `Stress = 0`.
  - `static class StressEffects`: `float CameraShake(float stress, SurvivalConfig cfg)` → 0 dưới `StressShakeStart`, tăng tuyến tính đến `0.05f` ở 100; `float SenseRadiusMultiplier(float stress, SurvivalConfig cfg)` → 1 dưới `StressSenseStart`, giảm tuyến tính đến `0.6f` ở 100; `float EnergyRegenMultiplier(float stress, SurvivalConfig cfg)` → 1 dưới `StressEnergyStart`, `StressHighEnergyRegenMultiplier` từ 80 trở lên.
