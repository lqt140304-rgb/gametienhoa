# 0.5d — Bệnh tật: Nhiễm Nước Đọng, Thối Gel, Mờ Bào Tử: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Thêm 3 bệnh có nguyên nhân rõ trong thế giới, triệu chứng rõ và cách chữa rõ; thiếu Tinh Chất Sống làm dễ mắc bệnh; bệnh Thối Gel lây giữa người chơi trong co-op.

**Architecture:** Luật bệnh là C# thuần (`DiseaseKind`, `DiseaseRules`) để test. `SurvivalState` giữ thời gian còn lại của từng bệnh và áp triệu chứng trong `Tick`. Các nguồn lây (nước bẩn, xác thối, vết thương, bào tử, người bệnh ở gần) gọi `TryInfect`. HUD và màu thân báo bệnh. Bệnh được gửi kèm trạng thái người chơi (một byte) để người khác thấy và lây.

**Tech Stack:** Unity 6.6, URP, C#, EditMode tests, Netcode for GameObjects (chỉ một byte thêm vào `PlayerNetState`).

**Spec:** `docs/superpowers/specs/2026-11-17-underroot-survival-slice-design.md` mục 6.4 (bệnh tật) và 5 (thiếu Tinh Chất Sống dễ bệnh).

Không đổi `WorldSync`, `RescueController`, `NetWorld`. Lây bệnh quyết định **tại máy người bị lây** dựa vào vị trí và byte bệnh của bóng người chơi khác (không cần Host). ### Task 1: Luật bệnh (C# thuần)

**Files:** Create `Scripts/Survival/DiseaseKind.cs`, `DiseaseRules.cs`; Test `Tests/EditMode/DiseaseRulesTests.cs`.

**Interfaces:**
- `public enum DiseaseKind { StagnantWater = 0, RottenGel = 1, SporeBlur = 2 }`.
- `public static class DiseaseRules`:
  - `const int Count = 3;` `static string Name(DiseaseKind k)` ("Nhiễm Nước Đọng", "Thối Gel", "Mờ Bào Tử"); `static string Cure(DiseaseKind k)` (gợi ý chữa: "nghỉ ở nơi trú và uống nước sạch", "ăn thức ăn giàu Tinh Chất Sống", "ở xa vùng bào tử, ăn đủ Tinh Chất Sống"); `static float Duration(DiseaseKind k)` (180, 240, 150 giây); `static bool Contagious(DiseaseKind k)` (chỉ `RottenGel`).
  - Hằng số nguồn lây (xác suất): `DirtyWaterPerSecond = 0.04f`, `RottenBiteChance = 0.35f`, `HitChance = 0.08f` (đòn từ ngoài gây ≥ 3 sát thương), `HitMinDamage = 3f`, `SporePerSecond = 0.05f`, `ContagionPerSecond = 0.02f`, `ContagionRange = 3f`.
  - `static float InfectionMultiplier(float vitamin)`: 1 khi `vitamin ≥ 40`, tuyến tính lên 3 ở 0.
  - `static float RecoveryRate(DiseaseKind k, bool inShelter, bool inCleanWater, float vitamin)`: cơ sở 1 (giây bệnh mất mỗi giây); `× 2` khi `inShelter`; `StagnantWater` thêm `× 3` khi `inCleanWater`; `SporeBlur` thêm `× 2` khi `vitamin ≥ 60`.
  - `static float VitaminCure(DiseaseKind k, float vitaminGained)`: số giây bệnh mất khi vừa ăn: `RottenGel` = `6 × vitaminGained`, bệnh khác 0.
  - Triệu chứng: `ThirstDrainMultiplier(bool stagnant)` (1,6 khi bệnh, 1 khi không), `HealMultiplier(bool stagnant)` (0,6), `HealthDrainPerSecond(bool rotten)` (0,3), `HealthDrainFloor = 0.1f` (không hút khi máu ≤ 10% tối đa), `OrganRecoverMultiplier(bool rotten)` (0,5), `SenseMultiplier(bool spore)` (0,6), `StressPerSecond(bool spore)` (0,5).

- [ ] **Step 1: Test** (tên cố định): `NamesAndCuresExist`; `DurationsPositive`; `OnlyRottenGelIsContagious`; `InfectionMultiplierCurve` (≥ 40 → 1; 0 → 3; 20 → 2); `RecoveryRates` (cơ sở 1; trú 2; nước sạch chỉ nhân cho `StagnantWater` (3; trú + sạch = 6); vitamin 60 chỉ nhân cho `SporeBlur`); `VitaminCuresRottenGel` (10 điểm → 60 giây; bệnh khác 0); `SymptomMultipliersAreNeutralWhenHealthy` (tham số `false` → 1, 1, 0, 1, 1, 0).

### Task 2: Bệnh trong `SurvivalState`

**Files:** Modify `Scripts/Survival/SurvivalState.cs`; Test `Tests/EditMode/SurvivalDiseaseTests.cs`.

**Interfaces:**
- `public float[] DiseaseTime` (độ dài `DiseaseRules.Count`, khởi tạo bằng 0; `[Serializable]` nên khai báo như `Nutrients`); `[NonSerialized] public bool InCleanWater;` `[NonSerialized] public Func<float> Roll = () => UnityEngine.Random.value;` (test thay bằng giá trị cố định).
- `public bool Has(DiseaseKind k)` (`DiseaseTime[k] > 0`); `public byte DiseaseMask` (bit `1 << k`); `public void SetDiseaseMask(byte mask)` (cho bóng người chơi khác: đặt thời gian 1 nếu bit bật, 0 nếu tắt); `public void Infect(DiseaseKind k)` (đặt thời gian = `Duration` nếu đang thấp hơn); `public bool TryInfect(DiseaseKind k, float probability)` (nhân `InfectionMultiplier(Nutrient(Vitamin))`, so với `Roll()`, nếu trúng gọi `Infect`, trả true; không làm gì khi đã chết hoặc đã bệnh hoặc `probability ≤ 0`); `public void Cure(DiseaseKind k)`.
- Trong `Tick` (sau khối khát, trước chuyển hóa): với mỗi bệnh đang có, thời gian giảm `RecoveryRate(...) × dt` (kẹp ≥ 0). Tác động: tốc độ mất nước (trong khối khát) × `ThirstDrainMultiplier`; hồi máu × `HealMultiplier`; `Thối Gel`: nếu `Health > HealthDrainFloor × MaxHealth` thì `ApplyDamage(HealthDrainPerSecond × dt)` (không cộng căng thẳng theo cú đánh); `Mờ Bào Tử`: cộng `StressPerSecond × dt` vào độ biến thiên căng thẳng.
- `Feed(nutrition, profile)`: sau khi cộng chất, `Thối Gel` giảm `VitaminCure(RottenGel, nutrition × profile.Vitamin × gain)` giây (kẹp ≥ 0).
- `Damage()` công khai (đòn từ ngoài): nếu `amount ≥ HitMinDamage` thì `TryInfect(RottenGel, HitChance)`.
- `Reset()` xóa hết bệnh. `Revive()` giữ nguyên.

- [ ] **Step 1: Test** (tên cố định; `s.Roll = () => 0f` để luôn trúng, `() => 1f` để không): `HealthyChangesNothing` (số liệu giống `SurvivalThirstStressTests`: hồi máu 1,5/s, năng lượng 10/s, nhiệt 1,5/s); `InfectAndMask` (`Infect` đặt thời gian 180/240/150; `DiseaseMask` đúng bit; `SetDiseaseMask`); `TryInfectUsesRollAndVitamin` (xác suất 0,3: roll 0,5 không trúng; vitamin 0 → nhân 3 → 0,9 trúng; đã chết hoặc đã bệnh thì false); `StagnantWaterDrainsThirstAndSlowsHealing`; `RottenGelDrainsHealthButNotBelowFloor` và `RottenGelDoesNotKill` (mô phỏng 10 phút: `Health` không xuống dưới 10% tối đa trừ khi do nguyên nhân khác); `SporeBlurRaisesStress`; `DiseasesRunOutByThemselves` (mô phỏng bằng thời lượng: hết bệnh); `ShelterAndCleanWaterSpeedRecovery`; `VitaminCuresRottenGel` (`Feed(10, profile Vitamin=1)` giảm đúng 60 giây); `ExternalHitCanInfect` (roll 0: `Damage(5)` → có `RottenGel`; `Damage(2)` không); `ResetClearsDiseases`.
- [ ] **Step 2: FAIL. Step 3: Cài. Step 4: PASS cùng toàn bộ test cũ. Step 5: Commit** `feat(0.5d): diseases in survival state`
