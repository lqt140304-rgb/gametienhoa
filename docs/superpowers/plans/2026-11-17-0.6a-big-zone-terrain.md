# 0.6a — Khu 480 m: địa hình Terrain, mái hang, ranh giới: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Scene `Underroot_Lake` thành một khu **480 × 480 m** (đi ngang khoảng 8 phút ở 1 m/s) có địa hình đồi bằng Unity Terrain, mái hang vòm lớn với rễ buông xuống, ranh giới cứng, **giữ nguyên toàn bộ nội dung hiện có** trong vùng lõi phẳng.

**Architecture:** Hình dạng địa hình là hàm thuần C# (`TerrainShape`) để test độ phẳng, độ dốc, độ xác định; mái hang là bộ sinh mesh thuần (`DomeMesh`) cũng test được. `UnderrootLakeBuilder` ghép hai thứ đó thành `TerrainData` (lưu thành asset), mesh mái, ranh giới và đèn, thay cho mặt phẳng 120 m và tường thấp cũ.

**Tech Stack:** Unity 6.6 (`6000.6.9f1`), URP, module Terrain (đã có `com.unity.modules.terrain` và `terrainphysics` trong manifest), C#, Unity Test Framework (EditMode).

**Spec:** `docs/superpowers/specs/2026-11-17-underroot-survival-slice-design.md` mục 6.9 (bước (a) trong 3 bước (a)(b)(c)). Bước (b) chia vùng quần thể và sắp lại các vi sinh cảnh; bước (c) rải thực vật. **Ngoài phạm vi bản này.**

## Global Constraints

- Code **chưa từng được biên dịch** (không có Unity): mỗi task tự dò API kỹ, ghi "chưa biên dịch"; chủ dự án chạy Console và Test Runner.
- **Domain reload đang TẮT**: không tạo biến `static` thay đổi được; hằng số `const`/`readonly` thì được.
- Kích thước khu: `ZoneSize = 480` m. Vùng lõi **phẳng đúng cao độ 0**: `CoreHalf = 65` m (nửa cạnh 130 m). **Mọi vật hiện có** của hồ (nước nông, hốc sâu, nơi trú, tổ, cửa vào của B, điểm xuất hiện, tường) nằm trong |x|, |z| ≤ 65 và phải còn đứng đúng trên mặt phẳng y = 0.
- Độ dốc ngoài lõi đủ để slime trườn được: tối đa khoảng 0,6 (xấp xỉ 31°) trong |x|, |z| ≤ 210; vùng rìa trong 25 m cuối được dựng thành vách dốc.
- Tốc độ slime giữ **1 m/s**, hao đói giữ nguyên (không đổi `SlimeController`, `SurvivalConfig`).
- Co-op (đã có trong `main`): không đụng `Net/`, `Prey`/`Predator`/`Nutrient`/`WorldSync`/`RescueController`. Không sinh/xóa thực thể thế giới ở client. `Packages/manifest.json` giữ nguyên dòng `com.unity.netcode.gameobjects`; bản này không cần sửa manifest.
- Tránh API lỗi thời Unity 6.6: không `GetInstanceID`, không `FindObjectsByType` có tham số sort.
- `TerrainData` phải được **lưu thành asset** trước khi lưu scene; mesh mái cũng lưu thành asset (nếu không, scene mất địa hình khi mở lại).
- Một file một class; không tạo file `.meta`; làm trên nhánh `claude/youthful-mendel-yw0yza`, PR, chủ dự án bảo mới merge.
- Menu **Build Prototype Scene** và scene `Prototype_01` không được đổi hành vi.

### Task 1: Quy mô và hình dạng địa hình (C# thuần)

**Files:**
- Create: `Scripts/World/WorldScale.cs`, `Scripts/World/TerrainShape.cs`
- Test: `Tests/EditMode/TerrainShapeTests.cs`

**Interfaces:**
- Produces:
  - `public static class WorldScale { public const float ZoneSize = 480f; public const float CoreHalf = 65f; public const float CrawlSpeed = 1f; public static float CrossingMinutes(float distance, float speed); }` (`distance / speed / 60`).
  - `public static class TerrainShape`:
    - `public const float TerrainHeight = 60f;` (chiều cao tối đa của `TerrainData.size.y`), `public const float BaseOffset = 10f;` (mặt lõi y = 0 ứng với chuẩn hóa `BaseOffset / TerrainHeight`; terrain đặt ở `position.y = -BaseOffset`), `public const float CliffStart = 215f;`, `public const float CliffHeight = 45f;`
    - `public static float HeightAt(float x, float z, int seed)` → độ cao (m) so với mặt lõi, `0` khi `|x| ≤ CoreHalf` và `|z| ≤ CoreHalf` (nửa cạnh vuông, không tròn), chuyển mượt (smoothstep) từ 65 m đến 120 m ra ngoài, rồi đồi nhiễu nhiều tầng (fbm bằng `Mathf.PerlinNoise`, bước sóng chính ~150 m, biên độ tối đa +20 m, luôn ≥ 0) và vách dốc: từ khoảng cách vuông `max(|x|,|z|) > CliffStart` leo lên đến `+CliffHeight` ở rìa 240 m.
    - `public static float[,] Heights(int resolution, int seed)` → mảng `[resolution, resolution]` chuẩn hóa 0..1 cho `TerrainData.SetHeights` (chỉ số `[z, x]` theo quy ước của Unity), trong đó vị trí thế giới của ô là `-ZoneSize/2 + i * ZoneSize/(resolution-1)`; giá trị = `(BaseOffset + HeightAt(...)) / TerrainHeight`, kẹp 0..1.

- [ ] **Step 1: Viết test** (tên và khẳng định cố định)

```csharp
[Test] public void CrossingMinutesIsEightForZone() // CrossingMinutes(ZoneSize, 1f) ≈ 8.0 (sai số 0.01)
[Test] public void CoreIsExactlyFlat()             // lưới 5 m trong |x|,|z| ≤ 65 → HeightAt == 0 (sai số 1e-5)
[Test] public void HeightsNeverNegativeAndBounded()// lưới toàn khu → 0 ≤ HeightAt ≤ CliffHeight + 1
[Test] public void SlopesStayWalkable()            // lưới 2 m trong |x|,|z| ≤ 210: |Δh| giữa hai điểm kề ≤ 1.2 m
[Test] public void EdgeRisesToCliff()              // HeightAt(235, 0) ≥ 30; HeightAt(0, -239) ≥ 35
[Test] public void SameSeedSameHeightDifferentSeedDiffers()
[Test] public void HeightsArrayShapeAndRange()     // Heights(65, 1): chiều 65x65, mọi giá trị trong [0,1]; ô giữa == BaseOffset/TerrainHeight (sai số 1e-4)
```

- [ ] **Step 2: Chủ dự án chạy Test Runner → FAIL (lỗi biên dịch vì thiếu lớp là đúng kỳ vọng).**
- [ ] **Step 3: Cài `WorldScale` và `TerrainShape` theo Interfaces; biên độ và bước sóng phải đủ để `SlopesStayWalkable` đạt (nếu dò tay thấy dốc vượt, giảm biên độ chứ không nới test).**
- [ ] **Step 4: Test Runner → toàn bộ PASS, kể cả 53 test cũ.**
